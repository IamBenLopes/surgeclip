# surgeclip
Website for Surgeclip, served at https://surgeclip.app by Cloudflare Pages (auto-deploys from `main`).

Since 2026-11-24 the site is only a plain home page, privacy policy and terms (needed for Google/YouTube and Meta
sign-in), plus the Meta and TikTok sign-in callback pages. The full product site is kept at branch
`full-site-2026-11-24`; to bring it back, merge or copy that branch's files onto `main`.

Files: index.html, privacy.html, terms.html, 404.html, style.css, favicon.svg, meta-callback.html,
tiktok-callback.html, _headers, _redirects, robots.txt, .nojekyll.
