Signalcut

A personal desktop tool for editing and scheduling short gaming clips.

Signalcut runs on one person's own Windows PC. It cuts short vertical clips from gaming streams, lets its owner edit and approve each one, and then posts the approved clips to the owner's own YouTube channels, Instagram account, Facebook Page and TikTok account on a schedule.

How it uses YouTube

Signalcut uses the YouTube Data API only after the channel owner signs in with Google and allows it. It uses that access to:

  • read which YouTube channel the signed-in account owns, so the owner can confirm the right channel;
  • upload videos the owner has approved, with the title, description, tags and publish time the owner set;
  • check an upload's status, and remove an upload when the owner asks.

How it uses Instagram and Facebook

After the owner signs in with Facebook and allows it, Signalcut uses Meta's Graph API to list the Facebook Pages the owner manages and the Instagram professional accounts linked to them, so the owner can confirm where clips go. It then publishes clips the owner approved as Instagram Reels and Facebook Page Reels, with the caption the owner set, at the owner's chosen time, and checks whether each post went out.

How it uses TikTok

After the owner signs in with TikTok and allows it, Signalcut uses TikTok's Content Posting API to read the owner's posting options (who can view, comments, duet and stitch), shows them to the owner, and uploads clips the owner approved to the owner's own TikTok account with the caption and settings the owner chose.

Nothing is posted without the owner approving that clip first. Signalcut is not a public service and has no other users.
