Signalcut

A personal desktop tool for editing and scheduling short gaming clips.

Signalcut runs on one person's own Windows PC. It cuts short vertical clips from gaming streams, lets its owner edit and approve each one, and then uploads the approved clips to the owner's own YouTube channels on a schedule.

How it uses YouTube

Signalcut uses the YouTube Data API only after the channel owner signs in with Google and allows it. It uses that access to:

  • read which YouTube channel the signed-in account owns, so the owner can confirm the right channel;
  • upload videos the owner has approved, with the title, description, tags and publish time the owner set;
  • check an upload's status, and remove an upload when the owner asks.

Nothing is posted without the owner approving that clip first. Signalcut is not a public service and has no other users.
